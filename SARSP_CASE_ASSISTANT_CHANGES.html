SARSP Case Assistant - Change Summary

Workspace: contentflow
Date: 2026-08-13
Status: End-to-end flow validated

Objective

Build and operationalize a lightweight customer-facing SARSP Case Assistant that accepts a Case ID, starts SARSP validation, tracks execution progress, displays recommendation/results, lists missing documents and document findings, and provides downloadable results.json.

High-Level Outcome

  • The Case Assistant UI is available at http://localhost:8080/ inside the VM using the static dist folder.
  • The original ContentFlow admin interface remains available under the admin route.
  • The API can start SARSP case executions through /api/sarsp/cases/{case_id}/validate.
  • The API can poll SARSP execution status through /api/sarsp/cases/{case_id}/executions/{execution_id}.
  • The API reads final reports from farmacia-nueva-renewal/input/{case_id}/results.json.
  • The Blob-based pipeline is now configured as the SARSP pipeline: sarsp_pipeline__63825f55.

Known Follow-Up

Some validation results are AI-generated and may contain reasoning inconsistencies, such as text saying a license is expired while the stated date indicates it is current. That should be reviewed in validation prompts/rules separately from the Case Assistant UI and API integration.
